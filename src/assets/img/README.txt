═════════════════════════════════════════════════════════
IMAGE TIPS
═════════════════════════════════════════════════════════
• Hero slideshow images: 1920×1080 (landscape) for best results
• Project card photos:  1200×800 or larger, landscape orientation
• Product photos:       1200×900 — show the equipment clearly
• Format:               JPG (preferred) or PNG
• Keep file size under 500KB each for fast loading
• Name files EXACTLY as shown above (lowercase, hyphens, .jpg)

If you don't have a photo yet — no problem. The website automatically
shows a clean placeholder with the file name reminder until you add it.
